# PSV Tahun 5 — Simulator, Kuiz & Apresiasi Teknik Mozek

Laman pembelajaran interaktif yang boleh diterbitkan melalui GitHub Pages.

## Kandungan
- **Simulator (25 markah):** pilih warna dan warnakan 12 petak mozek.
- **Kuiz (15 markah):** 3 soalan objektif, 5 markah setiap satu.
- **Apresiasi (10 markah):** 2 soalan pemerhatian karya, 5 markah setiap satu.
- Jumlah keseluruhan: **50 markah**.
- Mesra telefon, tablet dan komputer; tiada library luaran diperlukan.

## Cara muat naik ke GitHub Pages
1. Muat turun dan ekstrak ZIP ini.
2. Buka repositori GitHub yang hendak digunakan.
3. Muat naik `index.html`, `README.md` dan semua fail imej bersama-sama ke root repositori.
4. Pastikan nama fail imej dikekalkan seperti dalam ZIP.
5. Pergi ke **Settings → Pages**, pilih branch utama dan folder `/ (root)`, kemudian tekan **Save**.
6. Buka URL GitHub Pages selepas penerbitan selesai.

**Penting:** jangan muat naik `index.html` sahaja kerana laman menggunakan imej sokongan dalam ZIP ini.
